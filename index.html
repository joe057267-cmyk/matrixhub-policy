MatrixHubx 隐私政策

生效日期：2026-10-28 · 最后更新：2026-10-28 · 版本 2.0

MatrixHubx（矩阵内容中台，以下简称“我们”）提供多平台内容排期、审批、发布与数据分析服务。本政策说明我们在您访问 MatrixHubx 网站、使用 MatrixHubx 应用，以及连接第三方社交平台账号时，如何收集、使用、存储、共享与删除您的信息。

TikTok 用户请先阅读：本产品通过 TikTok Login Kit 与 Share Kit 获取和传输数据。我们如何收集、存储、使用及删除您的 TikTok 用户数据（包括 OpenID、头像、昵称等），在第 4.2 节逐项说明。我们不会在未经您确认的情况下自动发布内容，也不会出售 TikTok 数据或将其用于广告画像。

1. 适用范围与运营主体

本政策适用于 MatrixHubx 提供的网站、Web 应用、移动端页面、接口（API）及相关服务（以下统称“本服务”）。本服务由 MatrixHubx 运营团队（以下简称“我们”）运营。

本政策不适用于第三方社交平台、支付机构或其他第三方独立向您提供的服务。您在这些平台上的信息处理行为，适用其各自的隐私政策与用户协议。我们建议您在使用前阅读对应平台的条款。

如您代表企业或其他组织使用本服务，您确认已获得该组织的授权，可以代表其同意本政策。

3. 使用目的与法律依据

我们仅为下列目的处理您的信息：

  • 创建与维护账户、验证身份、保持登录状态；
  • 在您完成审批后，通过平台官方接口代您发布内容；
  • 读取您已授权账号的数据，生成发布记录与统计报表；
  • 提供客服支持、处理争议与数据请求；
  • 保障服务安全，检测异常登录、滥用与攻击；
  • 计费、开票与履行税务等法定义务；
  • 以汇总或匿名方式改进产品功能与稳定性。

在适用欧盟或英国《通用数据保护条例》（GDPR）时，我们的法律依据包括：履行与您之间的合同、我们的合法利益（保障服务安全与改进产品）、您的同意（如非必需 Cookie 或可选数据），以及遵守法律义务。您可以随时撤回同意，但不影响撤回前已进行的处理。

我们不会出售您的个人信息，也不会将您的个人信息用于跨站行为广告。未经您的同意，我们不会将您的私有内容用于训练面向公众的通用人工智能模型；仅在您主动使用 AI 功能时，我们才会为生成结果处理相关内容。

4. 第三方平台授权数据

4.1 授权机制

当您连接社交平台账号时，我们使用该平台提供的官方 OAuth 授权流程。您将被引导至平台页面，由您选择授予哪些权限。我们只获得您明确同意的范围，不会索取或保存您的平台账号密码。授权令牌在服务端加密存储，并受最小权限与审计日志约束。

4.2 TikTok Login Kit 与 Share Kit

本产品通过 TikTok Login Kit 与 Share Kit 获取和传输数据。我们如何收集、存储、使用及删除您的 TikTok 用户数据（包括 OpenID、头像、昵称等），如下所述。

  • 收集方式：仅在您点击“连接 TikTok”并完成授权后，通过 TikTok 官方接口获取；分享内容仅在您在界面中选择并确认后传输。
  • 使用目的：账号绑定与身份识别、展示账号信息、执行您审批通过的内容发布或分享、回传发布结果与统计。我们不会将 TikTok 数据用于广告定向、用户画像、信用评估或出售给第三方。
  • 存储：TikTok 令牌与账号标识存储于我们的服务端，令牌加密保存；访问受最小权限、双因素认证与审计日志约束。

  • 共享：我们不会出售、出租或交易您的 TikTok 用户数据；仅在为提供服务所必需的基础设施服务商（受数据处理协议约束）或法律要求时共享。我们不会将 TikTok 数据共享给广告商或数据经纪人。
  • 删除：您可以在 MatrixHubx 的“账号管理”中断开 TikTok，或发送邮件至 matrix@matrixhubx.com 请求删除。您也可以在 TikTok App 中依次进入“设置与隐私 → 安全与权限 → 管理应用权限”，撤销 MatrixHubx 的访问。我们会在核验身份后 30 天内完成删除，并同步删除由该数据衍生的账号绑定记录。
  • 不收集：我们不会收集您的 TikTok 密码、私信内容、通讯录、设备通讯录或未授权的非公开数据。
  • 自动化边界：Share Kit 的最终分享由您在 TikTok 客户端内确认；我们不会绕过客户端自动发布，也不会进行批量注册、刷量、群发私信或规避平台限流。

我们对 TikTok 数据的处理同时遵守 TikTok 开发者条款与 TikTok 隐私政策。若本政策与 TikTok 的强制性要求存在冲突，以更严格者为准。

4.3 Google 与 YouTube API Services

当您使用 Google 账号登录或连接 YouTube 频道时，我们仅请求您启用功能所必需的数据：

  • 基本资料（姓名、头像）与电子邮箱；
  • 您授权频道的基本信息、视频元数据、发布状态与已授权的分析数据。

我们仅将这些数据用于：验证身份并关联账户；向您授权的频道上传视频；展示分析报表；处理与 YouTube 功能相关的客服请求。我们不会将 Google 或 YouTube 用户数据出售、出租或用于广告，也不会共享给广告商或数据经纪人；仅在受保密与数据处理协议约束的基础设施服务商，或法律要求时共享。

Google 与 YouTube 数据通过 HTTPS/TLS 传输，并采用行业标准措施存储；访问权限仅限于经授权人员。令牌仅在提供服务所必需的期间保留，您撤销授权或终止账户后，我们将停止访问并在合理期限内删除或匿名化相关数据。

您可以随时在 Google 账号的第三方连接页面撤销授权。我们对 Google API 数据的使用的遵守 Google API Services User Data Policy，包括 Limited Use 要求。使用 YouTube API Services 还须遵守 YouTube 服务条款 与 Google 隐私政策。

4.4 Meta 平台（Facebook、Instagram、Threads）

当您连接 Meta 旗下平台时，我们通过 Meta 官方 OAuth 获取您授权的主页、Instagram 专业账号或 Threads 资料，以及发布所需的权限。我们仅按您授予的范围调用接口，用于内容发布、读取发布结果与统计。

我们遵守 Meta 平台条款与开发者政策，不会出售 Meta 用户数据，不会将其用于广告定向，也不会在您撤销授权后继续访问。您可以在 Meta 账户的“应用和网站”设置中移除 MatrixHubx，或通过第 12 节的方式联系我们删除数据。若平台提供数据删除回调，我们会在收到通知后按平台要求完成删除。

4.6 撤销授权的通用方法

您可以在 MatrixHubx 的账号管理中随时断开任一平台，也可以前往对应平台的“已授权应用/第三方应用”设置中撤销访问。撤销后，我们将停止通过该授权访问数据，并在 30 天内删除对应令牌与关联数据，法律另有要求的除外。

5. Cookie 与本地存储

我们使用少量 Cookie 与浏览器本地存储维持服务运行：

  • 必需：登录会话、安全校验、负载均衡；缺少这些内容服务无法正常工作。
  • 偏好：语言、主题、侧栏状态等，保存在 localStorage，可随时清除。
  • 统计：如启用，仅用于汇总访问量与错误率，不用于识别个人或跨站追踪；您可通过浏览器设置或我们的提示选择退出。

我们不使用广告 Cookie，也不参与跨站行为广告联盟。您可以通过浏览器设置清除或阻止 Cookie，但这可能影响登录与部分功能。

6. 共享、委托处理、转让与披露

我们不会出售您的个人信息。仅在下列情形共享：

  • 经您明确同意或由您主动触发，向对应社交平台发送发布请求；
  • 向为我们提供云主机、对象存储、邮件、支付、日志等基础设施的服务商共享必要信息，其仅能按我们的指示处理，并受保密与数据处理协议约束；
  • 为遵守法律法规、司法或行政机关的合法要求，或为保护用户、公众与我们自身的合法权益；
  • 在合并、收购、重组或破产情形下，接收方须继续受本政策约束；如用途发生变更，我们会重新征得您的同意。

我们不会公开披露您的个人信息，除非获得您的同意或法律要求。我们也要求所有受托方采取适当的安全措施，不得将数据用于其自身目的。

7. 存储地点、安全与保留

您的信息存储于我们及受托服务商使用的云基础设施中，可能位于您所在国家或地区以外。我们通过加密传输、访问控制、日志审计与员工保密义务保护数据安全。互联网传输不存在绝对安全，我们会持续评估并改进防护措施。

若发生个人信息泄露事件，我们将按适用法律的要求评估风险，并在必要时通知您与监管机构。

数据类别保留期限

8. 您的权利

在适用法律范围内，您有权：

  • 访问与获取副本：了解我们持有哪些关于您的信息；
  • 更正与补充：修正不准确或不完整的信息；
  • 删除：在法定情形下要求删除；
  • 撤回同意：随时撤回基于同意的处理；
  • 限制或反对处理：在特定情形下要求限制或反对某些处理；
  • 数据可携带：以结构化、常用格式获取您提供的信息；
  • 注销账户：通过账号管理或邮件申请；
  • 投诉：向您所在地的数据保护监管机构投诉。

请发送邮件至 matrix@matrixhubx.com。为保护您的信息，我们可能需要先核验身份。我们将在 30 天内回复；如请求复杂或数量较多，可延长 30 天并通知您。法律另有更短期限的，从其规定。

地区补充：如您位于欧洲经济区或英国，您有权向当地监管机构投诉，并可要求了解我们向第三国传输数据的保障措施。如您位于加利福尼亚州，我们不会出售或共享您的个人信息用于跨情境行为广告，您享有知情、删除、更正与不因行使权利而受歧视的权利。

9. 未成年人

本服务面向企业与成年创作者，不面向 16 岁以下未成年人。我们不会有意收集未成年人的个人信息。若我们发现误收集了未成年人信息，将尽快删除。监护人如发现相关情况，请联系 matrix@matrixhubx.com。

10. 国际传输

由于我们的服务商可能位于不同国家或地区，您的信息可能被传输至您所在地以外的地方处理。我们会采取合同、访问控制与安全评估等适当保障措施，确保传输后的信息仍受本政策保护。如适用法律要求，我们会使用标准合同条款或其他认可的传输机制。

11. 政策更新

当我们的服务、数据处理方式或法律要求发生变化时，我们可能更新本政策。重大变更将通过页面公告或电子邮件通知您，并更新顶部的“最后更新”日期。未经您明确同意，我们不会削减您依据本政策享有的权利。建议您定期查看本页面。

12. 联系我们

如您对本政策有任何疑问、意见、投诉或数据请求，请联系：

  • 电子邮箱：matrix@matrixhubx.com
  • 官方网站：https://matrixhubx.com
  • 响应时限：核验身份后 30 天内
  • 适用产品：MatrixHubx 矩阵内容中台

如您对我们的回复不满意，您也可以向所在地的数据保护监管机构投诉。
