# MatrixHubx 开放平台申请用站点

平台名称：**MatrixHubx**（矩阵内容中台）；官方网站：https://matrixhubx.com

本仓库用于托管 MatrixHubx 在申请第三方开放平台（TikTok、Meta、Google/YouTube 等）开发者应用时所需的公开页面。

## 页面

| 语言 | 隐私政策 | 服务条款 |
| --- | --- | --- |
| 中文 | `index.html` → https://joe057267-cmyk.github.io/matrixhub-policy/ | `terms.html` → https://joe057267-cmyk.github.io/matrixhub-policy/terms.html |
| English | `privacy-en.html` → https://joe057267-cmyk.github.io/matrixhub-policy/privacy-en.html | `terms-en.html` → https://joe057267-cmyk.github.io/matrixhub-policy/terms-en.html |

提交 TikTok 开发者审核时填写英文版本链接：Privacy Policy 用 `privacy-en.html`，Terms of Service 用 `terms-en.html`。

## 内容要点

- TikTok Login Kit / Share Kit 专项披露：获取的数据（OpenID、头像、昵称、主页链接、统计等）、用途、存储、保留、共享与删除路径。
- Google / YouTube API Services 的 Limited Use 声明与撤销授权入口。
- Meta 平台数据使用与删除说明。
- 禁止行为覆盖批量注册、刷量、自动挂机、群发私信、抓取与规避限流。
- TikTok 品牌规范：官方按钮素材不做修改。

## 维护

样式在 `assets/policy.css`。修改条款后请同步更新四个页面顶部的“最后更新”日期与版本号。
